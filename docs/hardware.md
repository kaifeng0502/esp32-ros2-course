# 硬件与供电

本表对应参考样机；引脚必须以你的开发板丝印、模块资料和电机定义核对，尤其不能把线色当通用标准。

## 器材

ESP32-S3 N16R8开发板、1.3英寸SH1106 128×64 I²C OLED、TB6612FNG双H桥模块、一个带双路编码器的N20减速电机和轮子、数据USB线、杜邦线、可靠接线端子、面包板、万用表，以及本实验已测量调到10V的电机直流电源。

## OLED

| OLED端 | ESP32 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SDA | GPIO8 |
| SCL | GPIO9 |

OLED和驱动逻辑占满3V3排针时，可从一个3V3引脚引到面包板电源排分配。同一段电源排导通，不同侧、正负排、中央断点可能不通；断电用通断档确认实际拓扑。标着“+”不代表它自带电压，只有接上3V3后才是3.3V电源排。

## TB6612FNG A通道

| 驱动板端 | 连接 |
|---|---|
| VCC | ESP32 3V3（逻辑电源） |
| GND | ESP32 GND，并与电机电源负极共地 |
| VM | 电机直流电源正极；本实验测量为10V |
| PWMA | GPIO4 |
| AIN1 | GPIO5 |
| AIN2 | GPIO6 |
| STBY | GPIO7 |
| AO1 | 本实例电机M1白线 |
| AO2 | 本实例电机M2红线 |

VM与VCC用途不同。不要把10V接到ESP32的3V3、GPIO或OLED上。驱动模块的商品页可能把VCC写成固定5V，本课程样机使用3.3V逻辑，具体模块须核对芯片/板级资料。B通道本课程未使用。

## 编码器

| 实例线色/功能 | ESP32 |
|---|---|
| 黑 VCC | 3V3 |
| 蓝 GND | GND |
| 绿 C1 | GPIO11 |
| 黄 C2 | GPIO10 |

两路是同一个电机的正交编码器信号，不是两台电机。GPIO10/11均可读脉冲；调换信号或电机方向会改变符号，需重新确认`encoder_sign`。本课程标定为每路1400边沿/车轮圈，不能与A/B合并四倍频等其他计数口径混用。

## 通电顺序与万用表

1. 接线、换端子、测电阻/通断时先断开USB和电机电源。
2. 本课程只测适配器的低压输出，不拆适配器或测市电插座。黑笔COM、红笔V/Ω，直流电压档确认电压和极性；不要用电流档跨接电源。
3. 只接USB验证逻辑和编码器。蓝线对ESP32 GND应接近0V，黑VCC对蓝GND应接近3.3V。
4. 车轮悬空并固定电机，接通已确认的10V，显式发送有限时长命令。
5. 结束时停止任务、断电机电源，再按需要拔USB。驱动关闭之后轮子仍可能滑行。

裸线需要适配的端子或焊接。杜邦公头能夹住不等于可靠电连接，应断电检查连续性并轻拉确认。不能把两路信号接在面包板同一组相连的孔里。
