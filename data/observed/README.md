# 参考样机的观察记录

三个 `.txt` 是学习过程中保存的终端输出，已移除个人路径与提示符。`metrics.csv` 逐行转录这些输出末尾的24项统计，未重新计算或补造原始样本。

| 文件 | 实验 |
|---|---|
| baseline_w2.txt | PID与普通MPC，输入变化权重2，两轮80→110 RPM |
| weight_w8.txt | 输入变化权重改为8，其他比较方式不变 |
| capped_margin1.txt | 普通MPC与预测约束MPC，1 RPM余量，两轮80→110 RPM |

终端约每0.2秒显示一次，底层控制/完整记录约50ms一次。这里没有Ubuntu上完整的高频CSV，因此不能从终端曲线精确重算峰值、IAE或约束违反；统计字段保留当时程序打印的结果。`overshoot_percent`在后续目标切换阶段按阶跃幅度归一化，不能直接用它乘目标110来反推RPM峰值。较早两份记录没有打印绝对超调RPM，该列留空。

`model-summary.json`是六位小数模型系数和验证指标的转录，**不是可直接烧录的模型文件**。实际实验须运行第19节辨识，生成含完整精度、验证与采样信息的自己的`model.json`。

所有数据来自同一套参考硬件与当时的10V供电、空载轮子。没有把未采集的负载试验、置信区间或最坏情况保证补成结果。
